# IOCap Sandbox

This repository (WIP) contains all of the relevant programs, hardware designs, experiments, and results used in the creation of Samuel W. Stark's thesis.
Please contact <mailto:samuel.stark@cl.cam.ac.uk> with any questions.

## Checking out

This repository contains many submodules, which hold most of the relevant code.
If checking out all content, I recommend using `--depth=1` to avoid downloading redundant data, especially from CheriBSD which is a large repository.

```
$ git submodule update --init --recursive --depth=1
```
